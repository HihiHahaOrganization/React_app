# Мануал + Отчёт по фронтенду проекта «Интеграция прайсов»

---

## 1. Описание структуры проекта

- `src/api/` — модули для работы с backend API, все запросы централизованы здесь.
- `src/components/` — React-компоненты пользовательского интерфейса.
- `src/index.css` — глобальные стили.
- `src/App.jsx` — главный компонент приложения.
- `src/main.jsx` — точка входа приложения.
- В корне — конфигурационные файлы (`vite.config.js`, `tailwind.config.js`), `package.json` с зависимостями и скриптами.

---

## 2. Запуск и разработка

- Установка зависимостей: `npm install`
- Запуск dev-сервера: `npm run dev` (обычно доступно по адресу, который выводит Vite, например, `http://localhost:5173`)
- Для корректной работы API backend должен быть запущен и доступен по адресу, указанному в `src/api/config.js`

---

## 3. Сборка и деплой

- Сборка продакшен-версии: `npm run build`
- Сборка создаёт папку `dist/` с готовыми к публикации файлами
- Локальный просмотр сборки: `npm run preview`

---

## 4. Конфигурация

- Адрес backend сервера задаётся в `src/api/config.js` через константу `BASE_URL`
- В текущей версии проекта значение `BASE_URL` задаётся вручную, без использования переменных окружения

---

## 5. Рекомендации по деплою

- Папку `dist/` нужно разместить на статическом сервере или хостинге (Nginx, Netlify, Vercel и т.п.)
- Сервер должен отдавать `index.html` для всех маршрутов, чтобы SPA работал корректно
- Убедиться, что `BASE_URL` в конфиге указывает на доступный backend
